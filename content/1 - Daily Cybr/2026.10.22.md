## Mini-Report

In this challenge, we have to intercept traffic between the client (our friend) and the db using the weknesses of the ARP protocol.

Firstly, we begin by checking if ip_forward is on:
`root@7f6350d5c97b:~# cat /proc/sys/net/ipv4/ip_forward
`1`
**This is crucial for the ARP spoofing attack to work, otherwise the victim will just lose connection and nothing will work !**



Next, we need to understand what is the ARP spoofing attack and how it works: 
Simply, the db and the client need to know each other IP addr and MAC addr to communicate (for example, you need to know someone's name to communicate properly with they and where they lives so you can visit them).

This exchange rely on the ARP, an absurdly simple protocol that you can easily hack.

In fact, if you tell the victim "Hey! I'm the database here is my IP and my MAC", but you give your MAC instead, and you tell the database "Hey! I'm the victim, here is my IP and MAC", but you also give your MAC instead : You will be placed in the middle of their communication !

Let's use a IRL example to better understand this concept:
Imagine Bob (a nerdy french boy) and you want to communicate with Alice (a cute Asian girl) about music. If a malicious person usurp the identity of Bob by saying to Alice "Hey I'm Bob, talk to me in [the malicious person channel]" and says to Bob "Hey I'm Alice, talk to me in [the malicious person channel]". Both Alice and Bob will talk to the malicious person first before communicating for real.

Now that we master the concept, we can start the exploitation by using `arpspoof`.
We can see, thanks to the `tcpdump` tool, that the client will ask in the table "flag", what is written in the row 0 by default: `SELECT flag FROM flag limit 0,1`

So, we need to try to modify the query so that the client asks for the next row and we can see the flag.
To achieve this, we need scapy, a very useful python package for this situation.
Personally, i explained AI (Kimi K3) the context (arpspoof, what i wanted to achieve) and asked for a python script using scapy and forced myself to understand each line of code before using it.
